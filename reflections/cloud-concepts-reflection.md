# Cloud Concepts Reflection

## Reflection

Cloud computing has become an important part of my daily life because many of the applications I use rely on cloud services. Three cloud services that I regularly use are Google Drive, Facebook Messenger, and Canva. Google Drive allows me to store my files online, access them from different devices, and share them with classmates. It is an example of **Software as a Service (SaaS)** because I use the application directly through the internet without managing the underlying infrastructure. It also uses the **Public Cloud** deployment model since it is available to anyone with a Google account.

Facebook Messenger is another example of **SaaS** and uses the **Public Cloud** because it provides online messaging services that are accessible through the internet. It allows me to communicate with my classmates, instructors, and friends anytime and anywhere.

Canva is also a **SaaS** application hosted on the **Public Cloud**. It helps me create presentations, posters, and other school projects without installing professional design software on my computer.

Git and GitHub play an important role in cloud computing projects because they help developers manage changes to files and collaborate efficiently. Version control makes it possible to keep track of every update, restore previous versions when mistakes occur, and allow multiple team members to work on the same project without overwriting each other's work. GitHub also provides an organized platform for storing project files, documenting progress, and sharing work with instructors and teammates. As an IT student, learning Git and GitHub will help me develop better collaboration skills and prepare me for real-world software and cloud computing projects.
